My Nordic Race Results - v3 fixes

1. Endurance Promotions ResultsKey is treated as a per-result row id, not an athlete id.
   Athlete history is now grouped by normalized name + school (fallback team/city), so one athlete can have results across multiple races.

2. Endurance Promotions ASP.NET result-grid pagination now tries the existing query-string pager and falls back to a real ASP.NET form postback for pages 2+.
   The scraper logs the number of rows found on every result-grid page.

3. The scraper accepts both "Total Time" and "Time" result-table headers and infers gender from fields such as GJV/GVAR/BJV/BVAR when Gender is not present in the main grid.

4. Result deduplication no longer uses ResultsKey, because ResultsKey changes between races.

5. "Is this you?" review is one candidate at a time and only one athlete can be confirmed as "me" for the active profile.

6. Saving/changing an athlete profile clears old match decisions, so changing the name to another athlete does not inherit the previous person's identity.

7. GitHub Actions runs the scraper with --batch-size 10, --concurrency 4, --expose-gc and the 1723 start point.
